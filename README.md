# PSE25-27 — Application de révision

Page web de révision (quiz, flashcards, fiches lues à voix haute, TP,
infographies, podcasts, chansons) : https://guiraudjb.github.io/PSE25-27/

Ce dépôt ne contient que l'application. Les modules sont répartis dans des
dépôts thématiques, listés dans `catalogue.json` et publiés chacun par
GitHub Pages sur le même domaine :

- [pse-securite-nationale](https://github.com/guiraudjb/pse-securite-nationale) — ANSSI, SGDSN, stratégies nationales
- [pse-cadre-public](https://github.com/guiraudjb/pse-cadre-public) — règlements UE, référentiels nationaux, DINUM
- [pse-bercy](https://github.com/guiraudjb/pse-bercy) — DGFiP et directions de Bercy
- [pse-cours-2527](https://github.com/guiraudjb/pse-cours-2527) — cours PSE 25-27
- [pse-expert-reseau](https://github.com/guiraudjb/pse-expert-reseau) — fascicules PSE Expert Réseau
