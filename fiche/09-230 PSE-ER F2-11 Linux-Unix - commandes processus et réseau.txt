PRINCIPALES COMMANDES LINUX / UNIX

1. GESTION DES PROCESSUS
ps : visualise les processus (multitâche). Options selon le système : ps -aux (BSD), ps -edf (AT&T / System V). ps -e (tous les processus), ps -l (forme longue : F, S, UID, PID, PPID, C, PRI, NI, SZ, WCHAN, TTY, TIME, CMD), ps axf (arborescence, façon pstree). Inconvénient : liste à un instant t seulement ; on ne peut jamais avoir la liste exacte des processus en cours.
top : améliore ps (affichage dynamique des processus et ressources), non standard partout.
htop : F7/F8 priorité, F9 tuer (avec choix du signal), F6 tri, F5 arbre, F3 recherche ; affiche mémoire et CPU par cœur, uptime, charge.
sar : collecte des activités système. sar -u (% CPU, défaut), sar -q (processus en attente), sar -r (mémoire centrale et swap). Ex. sar -u 2 5.
kill : envoie n'importe quel signal à n'importe quel processus du même propriétaire (appel système kill). kill -l liste les signaux. kill -9 (SIGKILL) : destruction brutale. kill -1 (SIGHUP, reload) : relecture de la configuration.
at : lancement différé (at parametre_temporel commande ; Ctrl-D pour sortir ; at -l liste les travaux en attente).
crontab : tâches répétitives. crontab -e (éditer), crontab -l (lister). Six champs : minute (0-59), heure (0-23), jour du mois (1-31), mois (1-12 ou nom), jour de la semaine (0-6, 0 = dimanche, ou nom), commande. Ajouter > /dev/null 2>&1 en fin de ligne pour ignorer toute la sortie. Tâches de maintenance de préférence en plage nocturne.

2. SAUVEGARDE ET RESTAURATION
tar : archive/désarchive. Options c (créer), v (verbeux), f (fichier), x (extraire), t (table de contenu), z (compression gzip). tar cf archive.tar /home/ ; tar czf archive.tar.gz /home/. Taille de l'archive ≈ taille des données (sans compression). Permet, contrairement à dump, de sauvegarder une partie seulement d'une partition, voire des fichiers sans rapport. Problèmes : ne sauvegarde pas correctement les numéros majeur/mineur de /dev (préférer /dev/MAKEDEV), gère mal les fichiers à trous (blocs non alloués sauvés en ASCII zéro) ; effacer les fichiers core avant sauvegarde par cron. Duplication d'arborescence : ( cd /usr/local ; tar cf - . ) | ( cd /mnt ; tar xf - ). Packages Internet : .tar.gz / .tgz (gunzip puis tar xvf).
Sauvegarde incrémentale avec tar : touch -t <date> .comparateur pour créer un repère daté, puis find ~ -newer .comparateur | tar -c -T - -f incrementale.tar.
cpio : programme traditionnel, mode caractères, multi-volumes, utilise stdin/stdout/stderr (opérateurs de redirection). Liste des fichiers fournie sur l'entrée standard, souvent via find : find /home/ | cpio -o > home-backup.cpio. Restauration : cpio -it < /dev/rfd0. Combiné à find pour des sauvegardes sélectives (find -mtime, -atime...).
dd : transfert de données brutes, utile entre systèmes différents et pour évaluer des problèmes de performances disque (I/O). Ex. dd if=/dev/rfd0 of=/u/bob conv=ascii (EBCDIC vers ASCII).
mt : manipulation des bandes magnétiques (pas une commande de sauvegarde) : avancer, reculer, rembobiner, marques de fin de fichier. mt -f /dev/rmt/0 (statut), mt -f /dev/rmt/0n fsf 1 (avancer d'un fichier).
rsync : proche de rcp, beaucoup plus d'options, utilise ssh par défaut (rsync -a source/ login@serveur:/destination/). Options : -r récursif, -l liens symboliques, -t dates, -g groupe, -o propriétaire, -D périphériques, -v verbeux, -z compression, -e ssh ; --del / --delete-after supprime sur la destination les fichiers absents de la source, --ignore-errors, --force ; -n liste sans exécuter. Peu pertinent de stocker données et sauvegardes sur le même disque physique.

3. COMMANDES RÉSEAU (CLASSEMENT PAR COUCHE DOD)
net-tools (ancien, 2001) vs iproute2 (récent, par défaut sur CentOS 7, Arch Linux) : ifconfig -> ip addr, arp -> ip neigh, route -> ip route, netstat -> ss. iproute2 ajoute NAT, gestion du cache et des tunnels.
Couche 1 (adresses physiques) :
- ifconfig / ip addr : informations et configuration des cartes réseau (adresse MAC, adresse IP, activation/désactivation, ajout/suppression d'adresses).
- arp -a / ip neigh : correspondances adresses MAC <-> adresses IP de la table ARP. Si des routeurs séparent deux hôtes, c'est la MAC de la gateway par défaut qui est stockée.
Couche 2 (IP) :
- route -n / netstat -rn / ip route : visualiser et configurer la table de routage.
- ping : envoie une requête ICMP echo-request, attend un echo-reply ; 4 requêtes par défaut sous Linux (configurable). Vérifie loopback (127.0.0.0/8), hôtes distants, équipements. Résolution de noms via /etc/hosts (liens statiques nom/IP), pas par DNS avec ping <nom>. Statistiques finales : min / avg / max / mdev (écart type, maximum deviation). Premier echo-request plus long (connexion setup). Options : -c nombre, -i intervalle en secondes (défaut 1 s), -s taille du paquet (+ 8 octets d'en-tête ICMP). Limite : ICMP peut être bloqué par les pare-feux.
- traceroute / tracert : suit le chemin d'un paquet en incrémentant le TTL à partir de 1 ; chaque routeur décrémente le TTL et émet un message ttl exceeded à 0. Cartographie du réseau. Pare-feux : blocage fréquent (lignes * * *).
- tcptraceroute : envoie des paquets TCP SYN (port 80 par défaut) au lieu d'UDP/ICMP ECHO, contourne les filtres courants. Messages ICMP d'erreur : !H (hôte inaccessible), !N (réseau inaccessible), !P (protocole inaccessible), !S (échec source route), !F (fragmentation nécessaire), !X (communication administrativement interdite).
Couche 3 (TCP/UDP) :
- netstat : statistiques des connexions TCP/UDP et sockets Unix (sous Linux depuis /proc/net/*). Sans option : sockets Unix. netstat -a (toutes connexions et ports), netstat -ntl (TCP, sans DNS, listeners), netstat -ntlp (+ PID / nom du programme). S'appuie sur /etc/services.
- ss (socket statistics) : équivalent iproute2. ss [OPTIONS] [STATE-FILTER] [ADDRESS-FILTER]. Options t/u/x (TCP/UDP/Unix), -a (toutes), -n (sans DNS), -l (à l'écoute), -p (processus/PID). États : established, syn-sent, syn-recv, fin-wait-1/2, time-wait, closed, close-wait, last-ack, closing, all, connected. Opérateurs de tri sur les ports (le/ge/eq/ne/gt/lt).

4. OUTILS D'ANALYSE DU TRAFIC RÉSEAU
tcpdump : affiche les en-têtes de paquets d'une interface (Unix, Linux, Mac, Windows). Se lance en root car il met l'interface en mode promiscuous (accepte tous les paquets). tcpdump -D (interfaces), tcpdump port http, tcpdump dst <ip> and port domain, tcpdump -w capture.dump (enregistre, format non clair), tcpdump -r capture.log (relit).
iptraf : analyseur de trafic IP coloré et interactif (ncurses), non installé par défaut (yum/aptitude install iptraf). iptraf -i eth0 (trafic IP), iptraf -s eth0 (TCP/UDP), iptraf -l eth0 (débit). Menus : Configure (résolution DNS inverse), Filters (adresses IP, ports).
Wireshark (ex-Ethereal, projet 1998) : analyseur de protocole et de réseau, gratuit, GUI ou ligne de commande, tous OS. Plus d'une centaine de protocoles, capture temps réel (mirroring de ports), relit tcpdump / Microsoft Network Monitor / Sniffer Pro. Deux types de filtres : filtres de capture (définis au démarrage, limitent la taille du journal) et filtres d'affichage (modifiables en cours, recherche précise, plus puissants). Trois panneaux : liste des paquets (Packet list pane : IP/MAC, ports, contenu ; MAC seule si couche 2, IP si couche 3+, port si couche 4+), détails de paquet (Packet details pane : par couche OSI, dépliable), dissection (Packet bytes pane : hexadécimal). Barre de statut : carte réseau, état de la capture, emplacement, taille, paquets capturés (P) / affichés (D) / marqués (M) / perdus.
tshark : Wireshark en ligne de commande. -f filtre de capture (syntaxe tcpdump), -i interface, -w fichier de sortie, -R filtre d'affichage, -z pour la dissection/statistiques, -a duration:N / filesize:N / files:N pour les captures en continu. editcap divise ou retire des paquets d'un fichier ; mergecap regroupe plusieurs fichiers.

5. COMMANDES DIVERSES
head : premières lignes d'un fichier (10 par défaut). tail : dernières lignes (nombre en argument, tail -5). wc : compte les mots par défaut, -l compte les lignes. file : type d'un fichier (ascii ou binaire). seq : série de nombres (seq 1000 ; seq 5 5 20 par pas de 5). grep : recherche une chaîne dans un fichier, -r pour la récursivité, accepte les expressions régulières. su / su - : changer d'utilisateur, sans option tente de se connecter en root.
